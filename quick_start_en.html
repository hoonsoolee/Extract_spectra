Workflow 1

Prepare and analyse one CERES file

Example: D:\FieldData\2026-08-21\Plot_001.ceres

Local Folder→Single File→Scan Folder→Plot_001.ceres→Read CERES Contents→Select A / VNIR→Quick Preview→Prepare Selected Entry
  1. Read CERES Contents scans record headers and creates a small index without loading the complete file into RAM.
  2. Choose the intended acquisition and sensor, such as A / VNIR or A / SWIR.
  3. Quick Preview reads only three bands to confirm that the selected entry is correct.
  4. Prepare Selected Entry streams that entry to a uint16 BIL/HDR pair under output/_ceres_cache/.
  5. Wait for the green “connected” message, select the analysis/report options, and click Start Analysis.
Current scope: this is safe, selective preparation of one CERES entry at a time. The current version does not automatically extract every internal entry from every CERES file. Run whole-folder batch analysis on entries already prepared as BIL/HDR.
Disk planning: the interface shows the estimated BIL size and peak RAM before preparation. The BIL cache can be much larger than the original compressed/container representation.
Workflow 2

Load a BIL and inspect a spectrum

For ENVI, keep the pair together and select the header in folder-scan workflows:

D:\FieldData\Plot_001.bil
D:\FieldData\Plot_001.bil.hdr
ROI Spectra→Select file→Downsample ×4→Load→Zoom→Box / Lasso / Polygon→Save CSV
  1. Open ROI Spectra. Select the file, or use Enter Path Manually / Browse.
  2. Load at downsampling 4 for the first check.
  3. Read the banner: Reflectance calibration applied means the graph can show reflectance; Raw DN means sensor counts only.
  4. Zoom if needed, then define the ROI using Box, Lasso, or Click Polygon.
  5. Inspect mean, median, variability, wavelength range, and Y-axis range. Display limits never delete bands from the CSV.
  6. With calibration active, switch between Calibrated Reflectance, Raw DN, and Raw/Calibrated Comparison.
  7. Choose a path and click Save CSV.
Healthy-leaf example: low red reflectance near 660 nm followed by a strong rise into the NIR is plausible. A sharp unexplained step, extreme value above 1, or discontinuity at a sensor boundary should trigger calibration review—not automatic smoothing.
Workflow 3

Obtain and verify useful clustering

First trialSingle File · Downsample 4 · K-Means · 6 clusters · Quick Field QC
Final trialReuse reviewed settings · increase resolution only after the preview is satisfactory

K-Means is a practical first check for VNIR or SWIR. By default, it clusters raw-DN spectral structure and applies the same masks to calibrated data for reflectance extraction. Hybrid uses reflectance when available because NDVI and brightness thresholds are physically scaled.

Always inspect the image result

Open Visual Cluster Review and compare the RGB, cluster colour map, adjustable overlay, boundaries, and isolated-cluster images. A useful result shows spatially coherent leaves, soil, deep shadow, and strongly illuminated regions. Cluster IDs themselves have no biological meaning.

Observed problemFirst adjustment
One leaf becomes many tiny regionsReduce the number of clusters.
Sunlit and shaded leaves are mergedIncrease clusters, or use Hybrid and tune brightness.
Soil and vegetation are merged in VNIRTry Hybrid and review the NDVI threshold.
SWIR does not contain red + NIRUse K-Means or SAM, not Hybrid.
Only one local plot is poorUse ROI Analysis & Re-clustering for that ROI only.
Glare or panel pixels are saturatedCorrect acquisition or mask them; clustering cannot restore clipped signal.
Decision rule: do not accept a result only because the colour map looks attractive. Check spectra, cluster area, boundaries, and stability across similar plots.
Workflow 4

Build and apply White/Dark calibration

Here, “white balance” means an empirical-line reflectance calibration for every wavelength:

Reflectance = a(wavelength) × DN + b(wavelength)

Use matching acquisitions

  • Panel image acquired close in time to the crop scene.
  • Certified values such as 0.99, 0.50, and 0.25.
  • Measured sensor Dark with lens covered or shutter closed.
  • Same sensor, bands, integration time, and gain.
Panel Calibration→Load panel image→Select clean panel ROI→Enter 0.99 / 0.50 / 0.25→Add This Region as Panel→Load Dark→Calculate Calibration
  1. Open Panel Calibration, select the reference image, and click Load.
  2. Drag inside a uniform panel area. Avoid edges, shadows, dirt, and glare.
  3. Enter the certified fraction: 99% = 0.99, 50% = 0.50. Click Add This Region as Panel and repeat.
  4. Select Measured Dark File, choose the matching Dark, and click Load Dark. Constant 100 DN is screening-only when no measured Dark exists.
  5. Click Calculate Automatic Reflectance Calibration.
  6. Review reconstructed panel spectra, wavelength-dependent weights, saturation/invalid bands, and QC grade.
Multi-panel rule: a 50% panel remains 0.50; it is never converted to 0.99. If a bright panel is saturated only in some bands, its weight drops to zero there and a valid lower-reflectance panel can support those bands.
QCWhat the software doesUser action
PASSConnects automatically.Visually review, then use for analysis.
REVIEWConnects for trial analysis with warnings.Inspect reconstruction and suspect bands before science use.
FAILSaves for audit but blocks automatic whole-field use.Redefine panel ROIs/Dark and rebuild.

Saved profile:

output/calibration/<panel-image>_weighted_dark_calibration.npz

It becomes active immediately when QC permits. Later runs search the source folder and output/calibration/; the sidebar also allows an explicit profile. Confirm the green calibration banner and these exported fields:

value_units = reflectance
calibration_applied = true
calibration_qc_status = PASS
normalization_mode = none

Model-ready spectral sets: enable Actual Spectra for Model Training in the sidebar. The default reproducibly samples up to 1,000 pixels from each final cluster. Hybrid analysis also records the original sunlit/shadow/soil class. Pixel rows from one image are nested observations, not independent yield or Vcmax samples; group and split them by file or plot ID.

Recommended sharing package

  1. Per-file or team HTML report.
  2. Field_Results.xlsx for a day-level batch, when generated.
  3. The calibrated reflectance CSV needed for later statistics.
  4. processing_manifest.json for traceability.
  • Calibration QC is PASS.
  • The report says Reflectance, not Raw DN.
  • Requested indices were actually calculated.
  • Cluster overlay matches meaningful regions.
  • No unexplained spectral jump or saturation warning remains.
