실전 빠른 사용법

CERES 항목 준비, BIL 스펙트럼 확인, 클러스터링 검수, White/Dark 반사율 보정과 결과 전달까지 실제 버튼 순서대로 설명합니다.

CERES / CBDFENVI BIL/HDRROI 스펙트럼반사율 QCHTML + CSV + Excel
CERES부터 시작보정파일 만들기
0단계

한국어 프로그램 실행

cd D:\Research\Hyperspectral\Extract_Spectra_v2
python -m streamlit run app.py

브라우저는 보통 http://localhost:8501에서 자동으로 열립니다.

  • ENVI 헤더와 바이너리를 같은 폴더에 둡니다.
  • 첫 확인은 공간 다운샘플링 4를 사용합니다.
  • 전체 배치 전에 단일 파일을 시험합니다.
  • Raw DN은 반사율이 아니라는 점을 기억합니다.
작업 1

CERES 파일 하나를 준비하고 분석하기

예시: D:\FieldData\2026-08-21\Plot_001.ceres

로컬 폴더→단일 파일 선택→폴더 스캔→Plot_001.ceres→내부 목록 읽기→A / VNIR 선택→빠른 미리보기→선택 항목 분석 준비
  1. CERES 내부 목록 읽기는 영상 전체가 아니라 레코드 헤더만 읽습니다.
  2. 원하는 촬영 구간과 센서(VNIR/SWIR)를 선택합니다.
  3. 빠른 미리보기로 선택한 영상이 맞는지 확인합니다.
  4. 선택 항목 분석 준비를 누르면 해당 항목만 output/_ceres_cache/의 uint16 BIL/HDR로 변환됩니다.
  5. 초록색 연결 메시지를 확인한 뒤 설정을 고르고 분석 시작을 누릅니다.
현재 범위: CERES 내부의 선택한 항목 하나씩 안전하게 준비합니다. 여러 CERES의 모든 내부 항목을 한 번에 자동 추출하는 기능은 아직 구현 전입니다. 전체 배치는 미리 준비된 BIL/HDR을 대상으로 실행하세요.
용량 확인: 준비 전에 화면에 선택 BIL 용량과 예상 피크 RAM이 표시됩니다. 캐시 BIL은 원본 CERES보다 커질 수 있습니다.
작업 2

BIL을 불러와 스펙트럼 확인하기

D:\FieldData\Plot_001.bil
D:\FieldData\Plot_001.bil.hdr

두 파일을 같은 폴더에 두고 폴더 스캔에서는 작은 .hdr를 선택합니다.

ROI 스펙트럼→파일 선택→다운샘플 ×4→로드→확대→Box / Lasso / Polygon→CSV 저장
  1. ROI 스펙트럼 탭에서 파일을 선택하거나 직접 경로를 입력합니다.
  2. 처음에는 다운샘플 4로 로드합니다.
  3. 배너에서 반사율 보정 적용됨인지 원본 DN인지 확인합니다.
  4. 필요하면 확대하고 Box, Lasso 또는 클릭 Polygon으로 잎/플랏 ROI를 지정합니다.
  5. 평균·중앙값·변동성과 파장/Y축 범위를 확인합니다.
  6. 보정이 있으면 보정 반사율 / 원본 DN / 원본·보정 비교를 전환합니다.
  7. 저장 경로를 정하고 CSV 저장을 누릅니다.
잎 스펙트럼 예: 건강한 녹색 잎은 보통 660 nm 부근이 낮고 NIR로 가면서 크게 상승합니다. 갑작스러운 계단, 1을 크게 넘는 값 또는 센서 경계의 불연속은 평활화보다 보정 QC를 먼저 점검하세요.
작업 3

클러스터링을 제대로 설정하고 검수하기

첫 시험 설정단일 파일 · 다운샘플 4 · K-Means · 6개 클러스터 · 빠른 필드 QC
최종 설정미리보기에서 검수한 설정을 그대로 쓰고, 필요할 때만 해상도를 올립니다.

K-Means는 VNIR/SWIR 모두에 사용할 수 있어 첫 확인에 편합니다. 기본은 원본 DN 구조로 클러스터를 만들고 같은 마스크로 반사율 스펙트럼을 추출합니다. Hybrid는 NDVI와 밝기 임계값 때문에 유효한 보정이 있으면 반사율을 사용합니다.

이미지상에서 반드시 확인

클러스터링 결과 이미지 검수에서 RGB, 컬러맵, 투명도 조절 오버레이, 경계선과 클러스터별 단독 이미지를 비교합니다. 번호 자체에는 생물학적 의미가 없으므로 위치와 스펙트럼을 함께 해석합니다.

화면 문제먼저 바꿔볼 것
잎이 너무 잘게 나뉨클러스터 수를 줄입니다.
밝은 잎과 그림자 잎이 합쳐짐클러스터를 늘리거나 Hybrid 밝기값을 조절합니다.
VNIR에서 토양·식생이 합쳐짐Hybrid와 NDVI 임계값을 시험합니다.
SWIR에 red/NIR이 없음Hybrid 대신 K-Means 또는 SAM을 사용합니다.
특정 플랏만 결과가 나쁨ROI 구역 분석·재클러스터링으로 그 ROI만 다시 시험합니다.
과반사/패널이 포화됨촬영 또는 마스크를 수정합니다. 클러스터링은 소실 신호를 복원하지 못합니다.
채택 기준: 컬러맵이 예쁜지만 보지 말고 클러스터 위치·면적, 경계, 스펙트럼과 유사 플랏에서의 반복성을 확인하세요.
작업 4

White/Dark 반사율 보정파일 만들기

여기서 White balance는 RGB 색감이 아니라 파장별 empirical-line 반사율 보정입니다.

Reflectance = a(파장) × DN + b(파장)

같은 조건의 자료 준비

  • 작물 촬영시간과 가까운 패널 영상
  • 인증 반사율 0.99, 0.50, 0.25 등
  • 렌즈 덮개/셔터를 닫고 획득한 Sensor Dark
  • 같은 센서·밴드·integration time·gain
패널 보정→패널 영상 로드→깨끗한 패널 ROI→0.99 / 0.50 / 0.25 입력→패널로 추가→Dark 로드→자동 보정 계산
  1. 패널 보정에서 reference 영상을 로드합니다.
  2. 패널 가장자리·그림자·먼지·glare를 피해 균일한 안쪽을 선택합니다.
  3. 인증값을 소수로 입력하고 이 영역을 패널로 추가합니다.
  4. 실측 Dark 파일을 선택해 Dark 로드합니다. 상수 100 DN은 빠른 점검용입니다.
  5. 자동 반사율 보정 계산을 누릅니다.
  6. 패널 복원, 파장별 가중치, 포화/무효 밴드와 QC를 확인합니다.
다중 패널 원칙: 50% 패널은 0.50 그대로 사용합니다. 99% 패널이 일부 파장에서 포화되면 그 구간의 가중치는 0이 되고 유효한 낮은 반사율 패널이 대신 사용될 수 있습니다.
QC프로그램 동작사용자 판단
PASS자동 연결그래프 확인 후 분석 사용
REVIEW경고와 함께 시험 연결논문용 사용 전 복원·의심 밴드 검토
FAIL감사용 저장, 전체 분석 자동 적용 차단패널 ROI/Dark를 다시 정하고 재생성
output/calibration/<패널영상명>_weighted_dark_calibration.npz

QC가 허용하면 즉시 연결되고, 다음 실행에서는 원본 폴더와 output/calibration/에서 자동 탐색합니다. 작물 영상 로드 후 초록색 배너와 다음 값을 확인합니다.

value_units = reflectance
calibration_applied = true
calibration_qc_status = PASS
normalization_mode = none

  3. 통계용 보정 반사율 CSV

  • 보정 QC가 PASS입니다.
  • 단위가 Raw DN이 아니라 Reflectance입니다.

빠른 문제 해결

자주 생기는 문제

증상확인할 것
ENVI/BIL이 열리지 않음바이너리와 .hdr를 같은 폴더에 두고 헤더를 선택합니다.
CERES 분석 시작 불가내부 항목 선택 후 선택 항목 분석 준비를 실행합니다.
반사율 배너가 없음보정파일 없음, 비호환 또는 QC FAIL을 확인합니다.
NDVI 계산 불가보정된 red와 NIR 파장이 모두 있는지 확인합니다.
스펙트럼이 계단처럼 뜀패널 가중치, 포화, 센서 경계와 보정 QC를 확인합니다.
분석이 너무 오래 걸림다운샘플 4, 단일 파일 시험 또는 실행 중지를 사용합니다.
