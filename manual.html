User Manual

CanopySpectra

From CERES to Science-Ready Field Spectra

This tool automatically classifies pixels in hyperspectral field crop images and extracts radiometrically traceable class/ROI spectra. It supports White/Dark or weighted multi-panel calibration, large local ENVI files, selectable reports, and separate raw-DN/calibrated-reflectance exports.

🌱 Hybrid (NDVI + K-means)
📊 K-Means Clustering
📐 Spectral Angle Mapping
🤖 Autoencoder (Deep Learning)
📄 Selectable HTML / Daily Report
📈 Raw DN + Reflectance Spectra

Installation Steps

  1. Open a terminal (Windows: press Win+R, type cmd; Mac/Linux: open Terminal).

  2. Download the tool from GitHub:

    git clone https://github.com/hoonsoolee/Extract_spectra.git
cd Extract_spectra

  3. Install all required Python packages at once:

    pip install -r requirements.txt

  4. (Optional) Install PyTorch — only needed for the Autoencoder method:

    pip install torch

  5. Verify the installation by starting the app:

    python -m streamlit run app.py

    Your browser should open automatically at http://localhost:8501.

2.1 Define an ROI and Extract Spectra — Step by Step

💡
Shortest path Run app.py → ROI Spectrum tab → select file → Load → choose ROI tool → draw ROI → inspect spectrum → save CSV

  1. Prepare the file. In the left sidebar, select a local data folder and click Scan Folder. Alternatively, use the 🪟 Select button in the ROI screen to choose an ENVI .hdr or its linked .bil file.

  2. Open the 📈 ROI Spectrum (ROI 스펙트럼) tab. Choose the hyperspectral file and downsampling level, then click 📂 Load. Use ×1 for a small image; start with ×4 or more for a multi-gigabyte file.

  3. Read the calibration-status banner. If a compatible calibration.npz is active or automatically discovered, calibrated reflectance is available. Without a profile, the graph and CSV contain raw DN.

  4. Use Full-width ROI image and the image-height slider for a larger working view. Very long line-scan images also show a row/column-range slider.

  5. For a small target, choose 🔍 Zoom and drag a box over the area. After the zoom is retained, switch back to Box, Lasso, or Polygon and define the actual ROI. Use ↩ Full View to reset.

  6. After the ROI is defined, mean, median, and standard-deviation spectra are calculated. With calibration connected, switch among Calibrated Reflectance, Raw DN, and Raw/Calibrated Comparison. The wavelength and Y-axis display ranges affect the plot only, not the saved full-band data.

  7. Confirm that the ROI outline and spectrum are correct, then click 💾 Save CSV. The suggested filename ends in _roi_reflectance.csv when calibrated and _roi_raw_dn.csv otherwise.

2.2 Build a White/Dark Reflectance Calibration — Step by Step

In this application, “making white balance” means building wavelength-specific reflectance calibration coefficients from panels of known reflectance and a Sensor Dark. It does not merely adjust RGB color, and the reusable product is calibration.npz, not whitebalance.bil.

  1. Open the 🎯 Panel Calibration (패널 보정) tab in app.py.

  2. Under 1. Open an image containing panels, select a reference scan or a field image containing the panels and click 📂 Load. Use downsampling ×1–2 when panels are small. Prefer a panel scan acquired close in time under the same illumination and camera settings as the target scene.

  3. Under 2. Define panel regions, use Box or Lasso to select only the interior of one panel. Avoid edges, shadow, soil, contamination, and specular glare. Zoom first if necessary.

  4. Review uniformity and saturated-band warnings. Enter a panel name and its certified reflectance—for example, 99%=0.990, 50%=0.500, or 25%=0.250—then click Add this region as a panel. Repeat for the other panels.

  5. Review the registered-panel table. The program does not convert a 50% panel into 99%; it uses the supplied reflectance. When only some wavelengths are saturated, that bright panel receives zero weight at those bands and a valid lower-reflectance panel can carry the calibration through them.

  6. Under 4. Sensor Dark, choose a measured Dark file or a manual constant DN. Publication work should use a lens-covered Dark acquired with matching integration time and gain. Use the default constant 100 DN only as a documented temporary fallback.

  7. Click Automatic Reflectance Calibration. The software evaluates saturation, signal above Dark, and inter-panel consistency, then estimates the wavelength-specific equation R = a × DN + b.

  8. Inspect the QC PASS / REVIEW / FAIL grade, valid bands, lower-panel fallback bands, coefficient CV, reconstructed panel spectra, panel-weight curves, and the calibrated RGB preview. Bands with no trustworthy panel signal remain NaN instead of being invented by interpolation.

Automatic-use rule: PASS is connected automatically; REVIEW is connected for trial analysis with a warning; FAIL is saved for audit but blocked from whole-field analysis. Synthetic constant Dark receives at least REVIEW.
💾
Saved location and automatic connection The profile is saved automatically as output/calibration/panel-image-name_weighted_dark_calibration.npz. PASS/REVIEW profiles become active for Full Analysis and ROI Spectrum; FAIL profiles are blocked. Later runs check both compatibility and QC status while searching the scene folder and output/calibration.

Classification Methods

How the algorithm groups pixels into classes — no labels needed

All seven methods are fully unsupervised — they discover natural spectral groupings automatically. Choose based on your image type and analysis goal.

Recommended

Hybrid (NDVI + Brightness + K-means)

Uses vegetation physics first, then statistical clustering. Best for standard field crop images with NIR coverage.

General Purpose

K-Means

Pure data-driven clustering. Works on any image regardless of spectral range. No vegetation index required.

Lighting Invariant

SAM — Spectral Angle Mapping

Compares the shape of spectra, not their brightness. Best for images with strong shadows or uneven lighting.

Deep Learning

Autoencoder

Neural network learns compressed spectral features, then clusters them. Requires PyTorch. Slowest but most flexible.

Auto Cluster Count

HDBSCAN

Density-based hierarchical clustering. Determines the number of clusters automatically. No need to set a class count.

Probabilistic

GMM — Gaussian Mixture Model

Soft probabilistic clustering. Models each class as a Gaussian distribution. Good when clusters have different shapes and sizes.

Spectral Unmixing

NMF — Non-negative Matrix Factorization

Decomposes spectra into pure endmember components. Each pixel is assigned to its dominant endmember. No negative values needed.

5.1 Hybrid — Recommended Default

The Hybrid method combines three techniques in sequence. It is the recommended starting point because it leverages well-established vegetation physics rather than relying purely on statistical grouping.

↑ Increase if non-plant pixels are incorrectly included in leaf classes.
↓ Decrease if too few leaf pixels are being detected (stressed/senescent crops).

⚠
No NIR Band? NDVI requires a Near-Infrared (~800 nm) and Red (~660 nm) band. If your image does not cover these wavelengths, the Hybrid method automatically falls back to K-Means. Switch to K-Means or SAM manually in that case.

5.2 K-Means

A classic unsupervised clustering algorithm. Makes no assumptions about vegetation indices or spectral bands — it works purely from the statistical structure of the data.

How it works

  1. PCA reduces the hundreds of spectral bands down to 15 principal components, capturing most of the variance while discarding noise.

  2. K-Means partitions the compressed spectral space into K clusters by iteratively minimising the distance from each pixel spectrum to its cluster centroid.

  3. Each cluster becomes one output class. The classes are colour-coded but not named — you interpret them from the spectral chart in the report.

Parameter

ParameterDefaultWhat it controls
Number of Classes 6 How many clusters to find. More clusters = finer separation but harder to interpret. Start with 6 and adjust after reviewing the report.
💡
When to use K-Means Use K-Means when your image lacks NIR bands (making NDVI unavailable), when you want a purely data-driven result without any vegetation-index assumptions, or as a quick comparison baseline against Hybrid results.

5.3 SAM — Spectral Angle Mapping

SAM compares spectra by measuring the angle between spectral vectors rather than their Euclidean distance. This makes it insensitive to illumination intensity — a sunlit and a shadowed pixel of the same material will have a small angle, even though their absolute reflectance values differ significantly.

How it works

  1. Endmember extraction: Representative spectra are automatically extracted from the image using PCA — no user-provided reference spectra needed.

  2. Angle comparison: Each pixel's spectrum is compared to every endmember. The spectral angle (in radians) is calculated — small angle = high similarity.

  3. Assignment: Each pixel is assigned to the class of the endmember with the smallest angle.

  4. Background threshold: If the smallest angle exceeds the angle threshold, the pixel is assigned to Background (class 0) — it does not sufficiently resemble any known class.

Parameters

ParameterDefaultWhat it controls
Angle Threshold 0.10 rad (~5.7°) Maximum allowed angle between a pixel and its nearest endmember. Pixels exceeding this are assigned to Background.
↑ Increase if too many pixels are Background (threshold too strict).
↓ Decrease for stricter matching.
Number of Classes 6 Number of endmembers (representative spectra) to extract and use as class prototypes.
💡
When to use SAM SAM is particularly useful for images with strong shadow gradients or varying illumination — such as images taken near sunrise/sunset, under partially cloudy conditions, or with topographic shading.

5.4 Autoencoder (Deep Learning)

The Autoencoder uses a small neural network to learn a compressed representation of each pixel's spectrum. K-Means clustering is then applied in this learned space, which can capture non-linear spectral relationships that PCA (used by the K-Means method) might miss.

How it works

  1. Encoder: An MLP compresses each spectrum (hundreds of bands) down to 16 latent dimensions.

  2. Decoder: Another MLP reconstructs the original spectrum from the 16-dimensional code. The network trains by minimising reconstruction error.

  3. Clustering: After training, K-Means clusters the 16-dim latent vectors to produce the final class assignments.

Parameters

ParameterDefaultWhat it controls
Training Epochs 60 Number of passes over the training data. More epochs = better compression, but longer runtime. Reduce to 20–30 for a quick test; increase to 100–150 for very complex images.
Number of Classes 6 Number of K-Means clusters applied to the latent space.
⚠
PyTorch Required The Autoencoder method requires PyTorch. Install it with: pip install torch
If PyTorch is not installed, selecting Autoencoder will cause an error when you click Run.

5.5 HDBSCAN — Hierarchical Density-Based Clustering

HDBSCAN (Hierarchical Density-Based Spatial Clustering of Applications with Noise) finds clusters of arbitrary shape by grouping pixels that are densely packed together in the PCA-reduced spectral space. Unlike K-Means or GMM, it does not require you to specify the number of clusters in advance — the algorithm discovers it from the data.

How it works

  1. PCA reduction: Spectra are reduced to 15 principal components to speed up density estimation.

  2. Density estimation: HDBSCAN builds a hierarchy of clusters by linking dense regions at progressively lower density thresholds.

  3. Noise rejection: Pixels in sparse regions are labelled as noise (HDBSCAN label = −1) and mapped to class 0 (Background) in the output.

Parameters

ParameterDefaultWhat it controls
min_cluster_size 50 Minimum number of pixels required to form a cluster. Increase for larger, broader clusters; decrease to detect smaller detail classes. For megapixel images, values of 200–1000 are common.
min_samples 5 Controls how conservative the clustering is. Higher values increase the number of noise pixels (class 0). Lower values are more permissive.
💡
When to use HDBSCAN Use HDBSCAN when you have no idea how many distinct material classes are present in the image, or when class boundaries are irregular. If the result contains too many noise pixels (class 0), lower min_samples. If too many small spurious clusters appear, raise min_cluster_size.

5.6 GMM — Gaussian Mixture Model

GMM models the spectral distribution of the image as a mixture of Gaussian probability distributions. Each pixel is assigned to the component (class) for which it has the highest posterior probability. Unlike K-Means, which assumes spherical equal-size clusters, GMM can model clusters of different shapes and sizes by learning full covariance matrices.

How it works

  1. PCA reduction: Spectra are reduced to 15 principal components (same as K-Means).

  2. EM fitting: The Expectation-Maximisation algorithm iteratively estimates the mean, covariance and weight of each Gaussian component.

  3. Hard assignment: Each pixel is assigned to the component with the highest posterior probability.

Parameters

ParameterDefaultWhat it controls
Number of Classes 6 Number of Gaussian components. Set via the Number of Classes slider. Same guidance as K-Means applies.
covariance_type full Shape of the covariance matrix per component. full is most expressive but slowest; diag or tied are faster for very large datasets.
max_iter 100 Maximum EM iterations. Increase if the algorithm does not converge (check the log for convergence warnings).
💡
When to use GMM GMM is a good alternative to K-Means when you expect classes with elongated or differently-sized spectral distributions — for example, a wide soil-moisture gradient or spectrally overlapping crop varieties.

5.7 NMF — Non-negative Matrix Factorization (Spectral Unmixing)

NMF decomposes the hyperspectral data cube into a set of endmember spectra (pure spectral signatures) and their corresponding abundance maps (how much of each endmember is present at each pixel). Because reflectance values are always non-negative, NMF is a natural fit for hyperspectral data. Each pixel is hard-assigned to its dominant endmember for visualisation.

How it works

  1. Factorization: NMF solves: Data ≈ W × H, where W (pixels × components) gives the abundance coefficients and H (components × bands) gives the endmember spectra.

  2. Hard assignment: Each pixel is assigned to the component (endmember) with the highest abundance value in W.

  3. Endmembers: The rows of H represent the extracted pure spectral signatures — these can be inspected in the HTML report.

Parameters

ParameterDefaultWhat it controls
Number of Classes 6 Number of endmember components to extract. Set via the Number of Classes slider.
max_iter 500 Maximum NMF iterations. Increase if the reconstruction error is still decreasing at convergence (check the log output).
💡
When to use NMF NMF is best suited for spectral unmixing tasks where you believe each pixel may be a physical mixture of a few pure materials (e.g. soil + leaf litter + vegetation). The extracted endmember spectra in the report can be compared against spectral libraries for material identification.

How many groups to divide the image into

The slider controls how many output groups (clusters) the algorithm will create. The right value depends on the complexity of your scene.

Running the Analysis

Step-by-step from configuration to results

  1. Configure all settings in the sidebar: Data Source, Processing Mode, Method, Parameters, and Output Folder.

  2. Click the blue "🚀 Run Analysis" button at the bottom of the sidebar.

  3. Analysis runs in a separate worker process, and elapsed time plus the recent log refresh about every two seconds. To cancel, click "Stop Analysis" in the sidebar or run-status panel. Only that analysis worker and its child processes are terminated.

  4. Files completed before cancellation remain in the output folder. Do not treat a file being written at the moment of cancellation as a final result; regenerate it in the next run.

  5. When done, a green banner appears: ✅ Analysis complete! · ⏱ Xs. The elapsed time helps you estimate full batch duration.

  6. In Open Recent Analysis Results, choose a report and click Open Selected HTML Report. You can also open the results folder locally or download the HTML when working on a remote server.

  7. Classification map thumbnails appear as a quick preview.

  8. The run log at the bottom of the page shows per-step timing and quality metrics.

Inspecting a CERES file before full conversion

  1. Choose Local Folder → Single File → Scan Folder, then select the .ceres file.

  2. Click Read CERES Contents. The software scans record headers, not image pixels, and lists logical entries such as A/VNIR, A/SWIR, and B/VNIR. Both 2024 CBDF v1 and newer CBDF v2 layouts are recognized, and the index is cached.

  3. Select one entry and click Quick Preview. VNIR uses visible RGB; SWIR uses 1650/1250/1050 nm false color. Only three bands are read directly from CERES, so the full hyperspectral cube is never loaded into RAM.

  4. After confirming the acquisition, click Prepare Selected Entry. Only that sensor/segment is streamed to a uint16 BIL/HDR cache under output/_ceres_cache and connected to the regular analysis input.

  5. Review the memory table for downsampling ×1/2/4/8 before running the analysis.

Current scope: indexed browsing, selection, low-memory preview, and selective extraction are implemented. Direct automated day-folder processing without BIL will require a later two-pass streaming classifier.

Separating clustering from reflectance extraction

By default, K-Means determines spatial clusters from raw-DN spectral structure. The same masks are then applied to the calibrated cube, saving both raw-DN and reflectance CSVs. Hybrid automatically uses reflectance when valid calibration is available because its NDVI and brightness thresholds are defined on that scale.

After the run, Visual Cluster Review places the analysis RGB, cluster color map, and adjustable overlay together. Select clusters, change opacity and boundaries, then open isolated-cluster images to verify separation of leaves, shadows, bright glare, and soil.

Team / Plot Daily Package

  1. Select Batch (all files) and open Team / Plot Daily Package.

  2. Enter the actual acquisition date and team name. If filenames are not plot IDs, select a metadata CSV with filename, plot_id, treatment, genotype, replicate, team, measurement_date columns.

  3. After analysis, use Team / Plot Daily Results to open the HTML/folder or download Field_Results.xlsx.

The package combines every plot's RGB+cluster overlay, fixed -1 to 1 NDVI tiles, and plot-level NDVI median/IQR comparison. It aggregates compact outputs without reopening the source cubes, so the additional RAM cost is small.

Inclusion rule: Only plots with value_units=reflectance, calibration_qc_status=PASS, and valid NDVI enter the daily aggregate. REVIEW, FAIL, and uncalibrated plots remain visible but move to Warnings. Pixels from different plots are never pooled; the plot is the statistical unit.

Field_Results.xlsx contains Dashboard, README, Field Summary, Cluster Summary, Reflectance Spectra, and Warnings sheets.

Understanding the HTML Report

A complete breakdown of every section in the output report

After each run, a file named report_YYYYMMDD_HHMMSS_{method}.html (e.g. report_20260408_130351_kmeans.html) is saved in the output folder. Open it in any browser (Chrome, Firefox, Edge, Safari). Its sections follow the selected Quick QC, Research Standard, or Custom preset; unselected cards are omitted.

9.1 Image Overview

The overview card displays only the images selected in the report builder:

ImageBands usedWhat to look for
RGB Composite Red ~660 nm, Green ~550 nm, Blue ~450 nm Natural-colour view of the field. Confirms the data loaded correctly and the scene looks as expected.
CIR False-Color NIR ~800 nm → Red, Red → Green, Green → Blue Healthy vegetation appears bright red/magenta. Use this to visually verify where vegetation is — it should align with the leaf classes in the classification map.
Classification Map All bands (output of algorithm) All classes shown at once in their assigned colours with a legend showing pixel count and percentage. First overall check of the classification result.
RGB + Cluster Overlay RGB plus semi-transparent class colours Checks whether leaves, bright tissue, shadowed tissue, soil, and background are spatially separated as intended.
Selected Index Maps NDVI / GNDVI / NDRE / PRI Calculated only from calibrated reflectance with suitable wavelengths. The report lists the actual bands used.

Click an image to enlarge it to the browser window. Click the background/close button or press Esc to return. On wide screens the report uses a two-column layout so leaf, shadow, and glare boundaries remain visible.

9.2 Per-Class Classification Images

One large image per class. The pixels belonging to that class are shown in the class colour; all other pixels are shown as a darkened greyscale background. This makes it easy to visually inspect each class in isolation.

Good classification:

The class pixels form a spatially coherent region — e.g. the entire leaf canopy, a contiguous patch of soil, or the shadowed side of rows.

Needs adjustment:

The class pixels are scattered randomly, or visually mix different materials (e.g. soil and leaves in the same class). Adjust parameters and re-run.

9.3 Classification Summary Table

A table listing each class with its pixel count, percentage of total image area, and a horizontal colour bar showing the proportion visually.

Check whether the distribution looks reasonable for your scene: a dense canopy image should have large leaf classes; a sparse crop image will have more soil/background.

9.4 Reflectance Spectra Chart

An interactive Plotly chart showing the selected mean and/or median spectrum for each class. The Custom/Research presets can also show ±1 standard deviation and the 25–75% IQR envelope.

The accompanying spectra_{method}.csv file contains 7 statistics per class per band:

Column suffixDescription

stdStandard deviation — spectral variability within the class.
medianPer-band median reflectance.
q25 / q7525th and 75th percentile reflectance.
mnaMedoid-Neighbourhood Average — mean of the 100 pixels closest to the class median in Euclidean distance. Removes outliers while averaging real pixels. More stable than the pure median.

9.5 Quality Assessment

Two metrics are automatically calculated to quantify how well the clusters are separated in spectral space.

Cluster Quality Score (Silhouette-based gauge)

The Silhouette Score (range: −1 to +1) measures how similar each pixel's spectrum is to its own class versus the nearest other class. It is converted to a 0–100% gauge for readability.

0% — Poor 25% 50% — Fair 75% — Good 100% — Excellent
ScoreRatingMeaning
90 – 100%ExcellentClasses are very well separated in spectral space.
75 – 90%GoodReliable classification for most scientific purposes.
50 – 75%FairSome class overlap. Consider adjusting parameters or trying a different method.
Below 50%PoorSignificant overlap. Try a different method, change the number of classes, or adjust thresholds.

Davies-Bouldin Index

Measures the ratio of within-cluster scatter to between-cluster separation. Lower is better. Values below 1.0 are generally good; values above 2.0 suggest significant class overlap. Unlike the Silhouette Score, there is no universal "ideal" cutoff — it is most useful for comparing two runs of the same image.

The HTML report displays a plain-language interpretation box below each metric:

Good (green tip):

Silhouette ≥ 75% and DB ≤ 1.0 — classes are well separated. Results are reliable for scientific analysis.

Fair / Poor (yellow or red tip):

Some or significant class overlap detected. The tip suggests specific actions: try a different method, adjust the number of classes, or tune thresholds.

9.6 Vegetation Separation Assessment

This section evaluates how accurately the algorithm identified vegetation pixels, using NDVI as an independent ground truth. It answers: of all pixels that NDVI says are vegetation, how many were correctly labelled as leaves?

MetricDefinitionHow to interpret
Recall True positive rate Of all pixels with NDVI > 0.15, what fraction ended up in a leaf class?
Low recall: leaf pixels are being missed, placed in soil/background. → Lower the NDVI threshold.
Precision Positive predictive value Of all pixels placed in a leaf class, what fraction truly have NDVI > 0.15?
Low precision: non-vegetation is being labelled as leaves. → Raise the NDVI threshold.
F1 Score Harmonic mean of Recall & Precision A single combined score. Above 0.85 is excellent. Below 0.60 indicates significant misclassification of vegetation vs. non-vegetation.

The HTML report shows a colour-coded verdict box below the metrics table:

  • F1 ≥ 0.85 — Excellent vegetation separation. No action needed.
  • 0.65 ≤ F1 < 0.85 — Acceptable. Review Per-Class Images to confirm.
  • F1 < 0.65 — Poor. The report provides specific guidance:
      • Low Recall (< 65%): leaf pixels are missed → lower the NDVI threshold.
      • Low Precision (< 65%): non-vegetation is labelled as leaves → raise the NDVI threshold.
ℹ
Note This metric is only shown for the Hybrid and K-Means methods, and only when the image contains NIR and Red bands for NDVI computation. If the section shows "No vegetation separation data available", your image may lack the required bands.

9.7 Raw-DN vs Calibrated-Reflectance ROI Diagnostics

In the main app's ROI Spectrum tab, load an image, select a box/lasso/click-polygon ROI, then switch among Calibrated Reflectance, Raw DN, and Raw/Calibrated Comparison. Comparison mode uses separate left and right y-axes, so the much larger DN scale does not hide a distorted reflectance shape.

Open Calibration suspect-band and coefficient diagnostics to inspect R = a × DN + b. The table flags invalid or non-positive gains, robust gain outliers, and ROI mean reflectance outside the broad screening range −0.05 to 1.20. These are review warnings only: the software does not silently rewrite calibration coefficients or delete bands.

Common issues and how to fix them
ProblemCauseSolution
ModuleNotFoundError A required Python package is not installed. Run: pip install -r requirements.txt
For Autoencoder: pip install torch
Unsupported format error The file extension is not recognised. Check the extension is .hdr, .tif, .tiff, .h5, .hdf5, or .mat.
ENVI file does not load The .hdr and data file are in different folders or have different names. Make sure the .hdr and its data file (.raw / .bil etc.) share the same base name and are in the same folder.
Classification map is mostly one colour NDVI threshold is too high, or the wrong number of classes. Lower the NDVI threshold (Hybrid) or try a different number of classes. Check the Quality Assessment score.
Too many Background pixels (SAM) Angle threshold is too strict. Increase the Angle Threshold (e.g. 0.10 → 0.20).
Processing is very slow Large image size or many epochs (Autoencoder). Set spatial_downsample: 2 in config.yaml to halve image dimensions. Reduce Autoencoder epochs to 20–30 for testing.
Browser does not open automatically Browser launch failed silently. Open http://localhost:8501 manually.
