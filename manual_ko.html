반사율 보정 · 클러스터링 · ROI 스펙트럼 · 선택형 리포트

2.1 ROI 지정 및 스펙트럼 추출 — 실제 사용 순서

💡
가장 짧은 경로 app.py 실행 → ROI 스펙트럼 탭 → 파일 선택 → 로드 → ROI 도구 선택 → 이미지에서 지정 → 스펙트럼 확인 → CSV 저장

  1. 파일을 준비합니다. 왼쪽 데이터 소스에서 로컬 폴더를 선택하고 폴더 스캔을 누릅니다. 또는 ROI 화면의 🪟 선택 버튼으로 ENVI .hdr나 연결된 .bil 파일을 직접 선택합니다.

  2. 상단의 📈 ROI 스펙트럼 탭을 누릅니다. 초분광 파일 선택에서 파일을 고르고 다운샘플링을 정한 다음 📂 로드를 누릅니다. 작은 영상은 ×1, 수 GB 이상 영상은 우선 ×4 이상으로 시험하는 것이 좋습니다.

  3. 보정 상태 배너를 확인합니다. 호환되는 calibration.npz가 활성화되거나 자동 발견되면 보정 반사율을 사용할 수 있습니다. 보정파일이 없으면 그래프와 CSV는 원본 DN으로 표시됩니다.

  4. 필요하면 🖼️ ROI 이미지를 전체 폭으로 보기와 이미지 화면 높이를 조절합니다. 긴 라인스캔 영상은 행/열 구간 슬라이더로 원하는 부분을 먼저 표시합니다.

  5. 작은 부분을 크게 보고 싶으면 🔍 확대를 선택하고 이미지에서 사각형으로 드래그합니다. 확대된 화면이 유지되면 다시 Box, Lasso 또는 Polygon 모드로 바꿔 실제 ROI를 지정합니다. ↩️ 전체 화면으로 확대를 해제할 수 있습니다.

  6. ROI가 지정되면 평균·중앙값·표준편차 스펙트럼이 자동으로 계산됩니다. 보정파일이 연결된 경우 보정 반사율, 원본 DN, 원본·보정 비교를 전환할 수 있습니다. 파장 범위와 Y축 범위도 그래프 위에서 조절할 수 있습니다.

  7. 스펙트럼과 ROI가 맞는지 확인한 후 아래의 💾 CSV 저장을 누릅니다. 보정이 적용되면 기본 파일명은 _roi_reflectance.csv, 미적용이면 _roi_raw_dn.csv로 제안됩니다.

ROI 도구마우스 사용법적합한 경우
⬚ Box ROI원하는 영역을 사각형으로 드래그합니다.플롯, 패널, 직사각형 처리구를 빠르게 지정할 때.
✏️ Lasso ROI잎이나 구역의 외곽을 누른 채 자유롭게 그립니다.불규칙한 작물 영역을 빠르게 감쌀 때.
🔺 Polygon 클릭 ROI경계 꼭짓점을 최소 3개 차례로 클릭하고 ✅ Polygon 완료를 누릅니다.잎 외곽처럼 정밀한 경계를 지정할 때.
🔍 확대보고 싶은 부분을 사각형으로 드래그한 뒤 ROI 모드로 돌아갑니다.길거나 화면에서 작게 보이는 영상의 정밀 ROI.
⚠
논문용 스펙트럼 확인 화면에 반사율 보정 미적용이 표시되면 결과는 원본 DN입니다. 아래 2.2 절에서 보정파일을 만든 뒤 같은 파일을 다시 불러오거나, 호환되는 보정파일을 선택해야 반사율 스펙트럼이 됩니다.

2.2 White/Dark 보정파일 만들기 — 실제 사용 순서

이 프로그램에서 흔히 말하는 “화이트밸런스 만들기”는 단순히 RGB 색을 맞추는 작업이 아니라, 패널의 알려진 반사율과 Sensor Dark를 이용해 파장별 반사율 보정계수를 만드는 작업입니다. 결과는 whitebalance.bil이 아니라 재사용 가능한 calibration.npz로 저장됩니다.

  1. 상단의 🎯 패널 보정 탭을 엽니다.

  2. 1️⃣ 패널이 찍힌 이미지 열기에서 패널 reference 영상 또는 패널이 함께 찍힌 현장 영상을 선택하고 📂 로드를 누릅니다. 패널이 작으면 다운샘플 ×1–2를 권장합니다. 대상 작물 영상과 가능한 한 가까운 시각, 같은 조명·카메라 설정으로 촬영한 패널 영상을 사용하세요.

  3. 2️⃣ 패널 영역 지정에서 Box 또는 Lasso로 패널 하나의 안쪽만 지정합니다. 가장자리, 그림자, 흙, 눈부심은 피합니다. 필요하면 먼저 🔍 확대로 패널을 크게 봅니다.

  4. 표시되는 균일도와 포화 밴드를 확인하고, 패널 이름과 인증 반사율을 입력합니다. 예: 99%=0.990, 50%=0.500, 25%=0.250. 그런 다음 ➕ 이 영역을 패널로 추가를 누르고 다른 패널도 반복합니다.

  5. 3️⃣ 등록된 패널 표에서 이름·반사율·포화 상태를 확인합니다. 프로그램은 50% 패널을 99%로 바꾸지 않고, 입력한 실제 반사율을 그대로 사용합니다. 일부 파장만 포화되면 그 밴드의 밝은 패널 가중치를 0으로 낮추고 정상인 낮은 반사율 패널을 사용합니다.

  6. 4️⃣ 센서 Dark 설정에서 실측 Dark 파일 또는 수동 상수 DN을 선택합니다. 논문용 처리는 같은 integration time·gain으로 렌즈를 막고 촬영한 실측 Dark를 권장합니다. Dark가 없을 때만 임시로 기본 상수 100 DN을 사용합니다.

  7. ✨ 자동 반사율 보정 계산을 누릅니다. 프로그램이 파장별 포화·Dark 대비 신호·패널 일치도를 검사하고, 유효한 패널을 결합해 R = a × DN + b의 계수를 계산합니다.

  8. 5️⃣ 자동 반사율 보정 결과에서 QC PASS / REVIEW / FAIL, 유효 밴드, 낮은 패널 대체 밴드, 패널 일치도(CV), 패널 재구성 스펙트럼, 가중치 그래프와 보정된 RGB를 확인합니다. 어떤 패널에서도 신뢰할 수 없는 밴드는 임의 보간하지 않고 NaN으로 남습니다.

QC 자동 적용 규칙: PASS는 자동 연결되고, REVIEW는 경고와 함께 시험 분석에 연결됩니다. FAIL은 파일을 점검 기록으로 저장하지만 전체 필드 분석에는 연결하지 않습니다. 합성 상수 Dark는 최소 REVIEW입니다.
💾
저장 위치와 자동 연결 계산이 끝나면 결과폴더/calibration/패널영상명_weighted_dark_calibration.npz에 자동 저장됩니다. QC PASS/REVIEW만 현재 세션의 분석 실행과 ROI 스펙트럼에 연결되고 FAIL은 자동 적용이 차단됩니다. 다음 실행에서는 영상 폴더와 output/calibration에서 호환성과 QC 상태를 검사합니다.
화면 경고의미와 조치
균일도가 낮음배경·그림자·패널 가장자리가 섞였을 수 있습니다. ROI를 패널 중앙으로 좁힙니다.
일부 포화 밴드해당 파장에서 그 패널만 제외됩니다. 같은 파장이 정상인 낮은 반사율 패널이 있으면 자동으로 이어서 사용합니다.
전 밴드 포화그 ROI는 패널로 등록할 수 없습니다. 더 낮은 반사율 패널 또는 노출을 낮춘 reference가 필요합니다.
합성 Dark 사용 중전 밴드 상수값을 사용한 임시 보정입니다. 결과 이력에 기록되며 최종 논문 분석에는 실측 Dark가 더 적합합니다.
보정파일 비호환대상 영상과 밴드 수 또는 파장축이 다릅니다. 같은 센서·설정의 패널 영상으로 다시 생성합니다.

딥러닝

Autoencoder

신경망으로 스펙트럼을 압축한 후 클러스터링. PCA가 놓치는 비선형 패턴 포착. PyTorch 필요.

HDBSCAN

밀도 기반 계층적 클러스터링. 클러스터 수를 자동으로 결정합니다. 클래스 수 설정 불필요.

확률적

소프트 확률적 클러스터링. 다양한 형태와 크기의 클래스를 모델링. K-Means보다 유연함.

스펙트럼 언믹싱

NMF — 비음수 행렬 분해

스펙트럼을 순수 엔드멤버와 풍도 맵으로 분해. 각 픽셀은 가장 풍도가 높은 엔드멤버에 할당.

5.2 K-Means

고전적인 비지도 클러스터링 알고리즘입니다. 식생 지수나 특정 밴드에 대한 가정 없이 순수하게 데이터의 통계적 구조만 사용합니다.

동작 원리

  1. PCA(주성분 분석)로 수백 개의 스펙트럼 밴드를 15개 주성분으로 압축합니다. 대부분의 분산을 유지하면서 노이즈를 제거합니다.

  2. K-Means가 압축된 스펙트럼 공간을 K개 클러스터로 분할합니다. 각 픽셀을 가장 가까운 클러스터 중심에 반복적으로 할당합니다.

  3. 각 클러스터가 하나의 출력 클래스가 됩니다. 클래스에는 색상이 지정되지만 이름은 없습니다 — 리포트의 스펙트럼 차트를 보고 직접 해석하세요.

파라미터

파라미터기본값역할
클래스 수 6 찾을 클러스터 수입니다. 클러스터가 많을수록 세밀하게 분류되지만 해석이 어려워집니다. 6으로 시작하고 리포트 확인 후 조정하세요.
💡
K-Means를 사용할 때 NIR 밴드가 없어 NDVI를 계산할 수 없을 때, 식생 지수 가정 없이 순수 데이터 기반 결과를 원할 때, 또는 Hybrid 결과와 비교 기준이 필요할 때 사용하세요.

5.3 SAM — 스펙트럼 각도 매핑

SAM은 스펙트럼 벡터 사이의 각도를 기준으로 유사도를 측정합니다 — 유클리드 거리(밝기 차이)가 아닙니다. 따라서 조명 강도 변화에 영향을 받지 않습니다. 같은 재질의 햇빛 픽셀과 그림자 픽셀은 반사율 값이 달라도 각도는 작습니다.

동작 원리

  1. Endmember 추출: PCA를 이용해 이미지에서 대표 스펙트럼을 자동으로 추출합니다. 별도의 참조 스펙트럼이 필요 없습니다.

  2. 각도 비교: 각 픽셀 스펙트럼과 모든 Endmember 간의 각도(라디안)를 계산합니다. 각도가 작을수록 유사합니다.

  3. 클래스 할당: 가장 작은 각도의 Endmember 클래스에 픽셀을 할당합니다.

  4. 배경 임계값 처리: 최솟값 각도가 임계값을 초과하면 해당 픽셀을 배경(클래스 0)으로 할당합니다 — 어떤 클래스와도 충분히 유사하지 않은 픽셀입니다.

파라미터

파라미터기본값역할
각도 임계값 0.10 rad (약 5.7°) 픽셀과 가장 가까운 Endmember 사이의 최대 허용 각도입니다. 초과 시 배경 처리됩니다.
↑ 높이면: 배경 픽셀이 너무 많을 때 (임계값이 너무 엄격).
↓ 낮추면: 더 엄격하게 매칭.
클래스 수 6 추출할 Endmember(클래스 대표 스펙트럼) 수입니다.
💡
SAM을 사용할 때 일출/일몰 직후 촬영, 부분 구름 조건, 지형 그림자 등 조명이 불균일하거나 그림자 편차가 큰 이미지에 특히 유용합니다.

5.4 Autoencoder (딥러닝)

작은 신경망으로 각 픽셀의 스펙트럼을 압축된 표현으로 학습한 후, 그 공간에서 K-Means 클러스터링을 수행합니다. PCA(K-Means 방법에서 사용)가 놓칠 수 있는 비선형 스펙트럼 패턴을 포착할 수 있습니다.

동작 원리

  1. 인코더: MLP가 수백 밴드의 스펙트럼을 16차원 잠재 공간으로 압축합니다.

  2. 디코더: 다른 MLP가 16차원 코드에서 원본 스펙트럼을 재구성합니다. 재구성 오차를 최소화하는 방향으로 학습됩니다.

  3. 클러스터링: 학습 완료 후 16차원 잠재 벡터에 K-Means를 적용해 최종 클래스를 결정합니다.

파라미터

파라미터기본값역할
학습 Epochs 60 학습 데이터 전체를 반복하는 횟수입니다. 많을수록 압축 품질이 높아지지만 시간이 더 걸립니다. 빠른 테스트에는 20~30, 복잡한 이미지에는 100~150이 적합합니다.
클래스 수 6 잠재 공간에 적용하는 K-Means 클러스터 수입니다.

PyTorch 필요 Autoencoder 방법은 PyTorch가 설치되어 있어야 합니다:
pip install torch

5.5 HDBSCAN — 계층적 밀도 기반 클러스터링

HDBSCAN(Hierarchical Density-Based Spatial Clustering of Applications with Noise)은 PCA로 축소된 스펙트럼 공간에서 밀도가 높은 픽셀들을 그룹화합니다. K-Means나 GMM과 달리 클러스터 수를 사전에 지정할 필요가 없으며, 알고리즘이 데이터에서 자동으로 결정합니다.

동작 원리

  1. PCA 축소: 스펙트럼을 15개 주성분으로 축소하여 밀도 추정을 빠르게 수행합니다.

  2. 밀도 추정: HDBSCAN이 밀도가 높은 구역을 계층적으로 연결하여 클러스터 계층을 형성합니다.

  3. 노이즈 처리: 희박한 구역의 픽셀은 노이즈(HDBSCAN 레이블 = −1)로 판정되어 출력에서 class 0 (Background)에 할당됩니다.

파라미터

파라미터기본값역할
min_cluster_size 50 클러스터 형성에 필요한 최소 픽셀 수. 값이 클수록 크고 적은 클러스터가 생성됩니다. 수백만 픽셀 이미지에서는 200~1000 범위가 일반적입니다.
min_samples 5 클러스터링의 보수성을 제어합니다. 값이 클수록 노이즈 픽셀(class 0)이 늘어납니다.
💡
HDBSCAN 사용 시기 이미지에 몇 개의 클래스가 있는지 알 수 없거나 클래스 경계가 불규칙할 때 사용하세요. 노이즈 픽셀(class 0)이 너무 많으면 min_samples를 낮추고, 작은 클러스터가 너무 많이 생성되면 min_cluster_size를 높이세요.

5.6 GMM — 가우시안 혼합 모델

GMM은 이미지의 스펙트럼 분포를 가우시안 확률 분포의 혼합으로 모델링합니다. 각 픽셀은 사후 확률이 가장 높은 컴포넌트(클래스)에 할당됩니다. 구형 등크기 클러스터를 가정하는 K-Means와 달리, GMM은 완전 공분산 행렬을 학습하여 다양한 형태와 크기의 클러스터를 모델링할 수 있습니다.

동작 원리

  1. PCA 축소: K-Means와 동일하게 스펙트럼을 15개 주성분으로 축소합니다.

  2. EM 피팅: 기대값-최대화(EM) 알고리즘으로 각 가우시안 컴포넌트의 평균, 공분산, 가중치를 반복적으로 추정합니다.

  3. 하드 할당: 각 픽셀을 사후 확률이 가장 높은 컴포넌트에 할당합니다.

파라미터

파라미터기본값역할
클래스 수 6 가우시안 컴포넌트 수. 클래스 수 슬라이더로 설정합니다. K-Means와 동일한 가이드라인이 적용됩니다.
covariance_type full 컴포넌트별 공분산 행렬 형태. full이 가장 표현력이 높지만 느립니다. 대용량 데이터에서는 diag 또는 tied를 고려하세요.
max_iter 100 최대 EM 반복 횟수. 수렴되지 않으면 늘리세요(로그에서 수렴 경고 확인).
💡
GMM 사용 시기 스펙트럼 분포가 길쭉하거나 클래스 크기가 다를 때 K-Means 대신 사용하세요. 예: 토양 수분 구배가 넓거나 스펙트럼이 겹치는 작물 품종이 있는 경우.

5.7 NMF — 비음수 행렬 분해 (스펙트럼 언믹싱)

NMF는 초분광 데이터 큐브를 엔드멤버 스펙트럼(순수 스펙트럼 시그니처)과 그에 대응하는 풍도 맵(각 픽셀에서 엔드멤버가 차지하는 비율)으로 분해합니다. 반사율 값은 항상 비음수이므로 NMF는 초분광 데이터에 자연스럽게 적합합니다. 각 픽셀은 풍도가 가장 높은 엔드멤버에 하드 할당되어 시각화됩니다.

동작 원리

  1. 분해: NMF가 Data ≈ W × H를 풀어냅니다. W(픽셀 × 컴포넌트)는 풍도 계수, H(컴포넌트 × 밴드)는 엔드멤버 스펙트럼입니다.

  2. 하드 할당: 각 픽셀을 W에서 풍도가 가장 높은 컴포넌트(엔드멤버)에 할당합니다.

  3. 엔드멤버: H의 각 행이 추출된 순수 스펙트럼 시그니처이며 HTML 리포트에서 확인할 수 있습니다.

CERES 파일을 전체 변환 전에 확인하기

  1. 로컬 폴더 → 단일 파일 선택 → 폴더 스캔에서 .ceres를 선택합니다.

  2. 🧭 CERES 내부 목록 읽기를 누르면 영상 픽셀은 읽지 않고 레코드 헤더만 검사하여 A/VNIR, A/SWIR, B/VNIR처럼 촬영 구간과 센서를 보여줍니다. 2024 CBDF v1과 신규 CBDF v2를 모두 인식하며, 인덱스는 결과 폴더에 캐시됩니다.

클러스터링과 반사율 저장의 분리

기본 K-Means는 원본 DN의 스펙트럼 구조로 클러스터를 결정합니다. 이후 같은 클러스터 마스크를 보정된 큐브에 적용하여 원본 DN CSV와 보정 반사율 CSV를 모두 저장합니다. 따라서 보정파일을 다시 만들더라도 공간 분할과 반사율 해석을 구분해 점검할 수 있습니다. Hybrid는 NDVI와 반사율 밝기 임계값을 사용하므로 유효한 보정이 있으면 반사율을 클러스터 입력으로 자동 선택합니다.

분석이 끝나면 클러스터링 결과 이미지 검수에서 분석 RGB, 클러스터 컬러맵과 RGB 오버레이를 나란히 봅니다. 표시할 클러스터, 색상 투명도와 경계선을 바꾸고 클러스터별 단독 이미지에서 잎·그림자·밝은 반사·토양이 원하는 대로 분리됐는지 확인합니다.

팀·플랏 일일 통합 리포트

  1. 전체 배치 처리를 선택하고 팀·플랏 일일 통합 리포트를 엽니다.

  2. 실제 측정일과 팀 이름을 입력합니다. 파일명이 플랏 ID가 아니면 filename, plot_id, treatment, genotype, replicate, team, measurement_date 열을 가진 메타데이터 CSV를 선택합니다.

  3. 분석 완료 후 팀·플랏 일일 통합 결과에서 HTML·폴더를 열거나 Field_Results.xlsx를 내려받습니다.

패키지는 모든 플랏의 RGB+클러스터 오버레이, 공통 -1~1 범위 NDVI 타일, 플랏별 NDVI 중앙값·IQR 비교를 제공합니다. 원본 큐브를 다시 열지 않고 파일별 결과만 집계하므로 대용량 배치 뒤에도 추가 RAM 사용이 작습니다.

통계 포함 규칙: value_units=reflectance, calibration_qc_status=PASS, NDVI 계산 가능 조건을 모두 만족한 플랏만 일일 평균에 들어갑니다. REVIEW·FAIL·미보정 플랏은 화면에는 남지만 Warnings 시트로 분리됩니다. 서로 다른 플랏의 픽셀을 직접 합치지 않으며 플랏을 통계 단위로 사용합니다.

Field_Results.xlsx는 Dashboard, README, Field Summary, Cluster Summary, Reflectance Spectra, Warnings 시트로 구성됩니다.

함께 저장되는 spectra_{방법}.csv 파일은 클래스별·밴드별 7개 통계값을 포함합니다:

9.5 품질 평가

클러스터가 스펙트럼 공간에서 얼마나 잘 분리됐는지 두 가지 지표로 자동 계산합니다.

클러스터 품질 점수 (Silhouette 기반 게이지)

Silhouette Score(범위: −1 ~ +1)는 각 픽셀 스펙트럼이 자신의 클래스와 얼마나 가깝고 다른 클래스와 얼마나 먼지를 측정합니다. 가독성을 위해 0~100%로 변환됩니다.

0% — 불량 25% 50% — 보통 75% — 양호 100% — 우수
점수등급의미
90 – 100%우수클래스가 스펙트럼 공간에서 매우 잘 분리됨.
75 – 90%양호대부분의 과학적 목적에 충분한 신뢰도.
50 – 75%보통클래스 간 겹침 있음. 파라미터 조정 또는 다른 방법 시도 권장.
50% 미만불량심각한 겹침. 다른 방법 선택, 클래스 수 변경, 임계값 조정 필요.

Davies-Bouldin 지수

클러스터 내 분산과 클러스터 간 거리의 비율을 측정합니다. 낮을수록 좋습니다. 1.0 이하는 일반적으로 양호, 2.0 이상은 클래스 간 겹침이 심함을 시사합니다. 절대적 기준보다는 같은 이미지에서 두 실행 결과를 비교할 때 유용합니다.

HTML 리포트는 각 지표 아래 색상 코딩된 해석 박스를 표시합니다:

양호 (녹색 팁):

Silhouette ≥ 75% 이고 DB ≤ 1.0 — 클래스가 잘 분리됨. 과학적 분석에 신뢰할 수 있는 결과.

보통 / 불량 (노랑 또는 빨강 팁):

클래스 간 겹침이 일부 또는 심각하게 감지됨. 팁에 구체적 조치(다른 방법 시도, 클래스 수 조정, 임계값 조정 등)가 제시됩니다.

9.6 식생 분리도 평가

NDVI를 독립적인 Ground Truth로 사용해 알고리즘이 식생 픽셀을 얼마나 정확하게 찾아냈는지 평가합니다. 즉, "NDVI가 식생이라고 말하는 픽셀 중 몇 %가 잎 클래스에 들어갔는가?"를 답합니다.

지표정의해석
Recall (검출률) 실제 양성 검출률 NDVI > 0.15인 픽셀 중 잎 클래스에 들어간 비율.
낮으면: 잎 픽셀이 토양/배경에 섞임 → NDVI 임계값을 낮추세요.
Precision (정밀도) 양성 예측 정확도 잎 클래스에 속한 픽셀 중 실제로 NDVI > 0.15인 비율.
낮으면: 비식생이 잎으로 잘못 분류됨 → NDVI 임계값을 높이세요.
F1 점수 Recall과 Precision의 조화평균 단일 종합 점수. 0.85 이상이면 우수. 0.60 미만이면 식생/비식생 분류에 심각한 오류가 있음.

HTML 리포트는 지표 표 아래 색상 코딩된 판정 박스를 표시합니다:

  • F1 ≥ 0.85 — 우수한 식생 분리. 별도 조치 불필요.
  • 0.65 ≤ F1 < 0.85 — 허용 가능. 클래스별 이미지를 확인하세요.
  • F1 < 0.65 — 불량. 리포트에 구체적 안내가 표시됩니다:
      • Recall < 65%: 잎 픽셀이 누락됨 → NDVI 임계값을 낮추세요.
      • Precision < 65%: 비식생이 잎으로 분류됨 → NDVI 임계값을 높이세요.
ℹ
참고 이 지표는 이미지에 NIR 및 Red 밴드가 있어 NDVI 계산이 가능할 때만 표시됩니다. "식생 분리도 데이터가 없습니다"가 표시되면 해당 밴드가 없는 이미지일 수 있습니다.

9.7 원본 DN ↔ 보정 반사율 ROI 진단

ROI 스펙트럼 화면에서 같은 구역을 유지한 채 원본 DN, 보정 반사율, 원본·보정 비교를 전환할 수 있습니다. 보정 결과가 이상할 때 ROI가 달라져 생기는 혼동 없이 보정 전후의 형태를 직접 비교할 수 있습니다.

💡
확인 순서 원본 DN에서 센서 신호와 포화 여부를 먼저 확인하고, 보정 반사율에서 0–1 범위와 식생의 red-edge/NIR 형태를 확인하세요. 비교 화면에서 특정 파장만 급격히 꺾이면 White/Dark 프로파일의 포화 밴드, 파장 정렬, 촬영 시간 일치 여부를 점검합니다.

class_map_{방법}.png 클래스 이름, 픽셀 수, 비율이 담긴 범례가 포함된 색상 분류 맵. 보고서나 발표 자료에 바로 삽입. 별도 소프트웨어 불필요.
report_*_{방법}.html 모든 이미지, 인터랙티브 차트, 표, 품질 지표가 담긴 독립 실행형 HTML. 브라우저에서 열기. 인터넷 불필요. Ctrl+P → "PDF로 저장"으로 PDF 변환 가능.
